# HxMonitor

HxMonitor 是一款基于 Qt 6 开发的 Windows 桌面监控与媒体控制中心。

它主要具备两大核心功能：
1. **硬件状态监控与外设桥接**：实时采集电脑的 CPU、内存、GPU、网络等硬件性能数据，并通过串口通信发送给外部硬件设备（如包含 LCD 屏幕的 ESP32 单片机），实现炫酷的桌面副屏硬件监控体验。
2. **全局媒体控制 (IPC Server)**：作为本地 IPC 服务端运行，与中间件代理（Proxy）配合，实现对电脑浏览器（如 Edge、Chrome）内媒体播放的全局控制（播放/暂停、上一首、下一首、画中画）。

## 核心特性
*   **多维度硬件监控**：集成自定义的 `CmdMonitor.exe` 采集模块，支持丰富的系统资源数据抓取。
*   **极简串口连接**：通过可视化下拉菜单一键连接硬件设备。
*   **无缝中间件对接**：采用跨语言友好的 Named Pipe (`\\.\pipe\MediaControlHubPipe`) 和 JSON 协议与 Proxy 高效通信。
*   **单实例防多开**：内置智能互斥机制，防止意外启动多份控制端导致资源冲突。
*   **便携部署**：绿色纯净运行，托盘后台常驻。

## 快速上手
1. 打开应用程序 `HxMonitor.exe`。程序会自动启动硬件信息采集子进程，并在窗口中可视化展示各项指标。
2. 在右上角的**「串口号」**下拉菜单中选择您外接设备所挂载的 COM 端口，点击**「连接」**。连接成功后，硬件指标数据将开始同步推送到外设。
3. 如果您已配置好了配套的 [MediaControl Proxy 开发环境](https://github.com/your-proxy-repo/media-control) 和浏览器扩展，可以打开浏览器播放随意音视频。此时 HxMonitor 底部的 **「浏览器媒体控制」** 列表中会自动出现当前正在播放的媒体项。
4. 选中列表项后，您可以点击下方的 **播放/暂停**、**下一首** 或 **画中画** 按钮，直接对浏览器进行远程遥控。
5. 关闭主界面后，程序会静默最小化至右下角系统托盘。如需退出，请右击托盘图标选择「退出」。
