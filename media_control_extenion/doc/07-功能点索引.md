## 一、内容脚本层（Content Script）

| # | 功能点 | 所在文件 | 说明 |
|---|--------|----------|------|
| C-1 | 媒体元素自动检测 | `content/detect/media.ts` → `find()` | 轮询 DOM 查找 `<video>` / `<audio>`，优先选正在播放的元素 |
| C-2 | 媒体状态上报 | `content/detect/media.ts` → `getState()` | 上报 playing / duration / position / title / artist / artwork |
| C-3 | Media Session API 元数据提取 | `content/detect/media.ts` → `getState()` | 最高优先级读取 `navigator.mediaSession.metadata` |
| C-4 | Open Graph 封面提取 | `content/detect/media.ts` → `getState()` | 读取 `og:image` meta 标签 |
| C-5 | 视频 Poster 封面提取 | `content/detect/media.ts` → `getState()` | 读取 `<video poster="...">` |
| C-6 | Bilibili 站点适配 | `content/detect/media.ts` → `getState()` | 特定选择器提取标题和封面 |
| C-7 | iframe 内标题降级 | `content/detect/media.ts` → `getState()` | iframe 内无意义标题置空，由 SW 用 Tab 标题回填 |
| C-8 | 播放/暂停控制 | `content/actions/control.ts` → `PlayPause` | `element.play()` / `element.pause()` |
| C-9 | 下一曲（快进 10s） | `content/actions/control.ts` → `Next` | `currentTime += 10`（通用 fallback） |
| C-10 | 上一曲（后退 10s） | `content/actions/control.ts` → `Prev` | `currentTime -= 10` |
| C-11 | 画中画切换 | `content/actions/control.ts` → `TogglePip` | `requestPictureInPicture()` / `exitPictureInPicture()` |
| C-12 | 内容状态查询响应 | `content/index.ts` | 响应 SW 的 `queryState` 消息 |
| C-13 | 状态上报频率控制 | `content/detect/media.ts` → `bind()` | `timeupdate` 事件节流为每秒最多 1 次 |
| C-14 | Extension Context 失效保护 | `content/index.ts` / `media.ts` | 检测 `chrome.runtime.id` + `stop()` 清理 |
| C-15 | 检测器清理接口 | `content/detect/media.ts` → `stop()` | 清除 interval + 解绑事件监听器，防止内存泄漏 |

📁 **空目录预留**：`content/report/` — 预计用于独立的状态上报逻辑

## 二、Service Worker 层（Hub Core）

| # | 功能点 | 所在文件 | 说明 |
|---|--------|----------|------|
| S-1 | 消息路由中枢 | `sw/hub/router.ts` | 统一处理 Runtime Message 和 Desktop Message |
| S-2 | 多标签页媒体状态管理 | `sw/hub/store.ts` → `updateMediaState` | 按 `tabId` 存储每个标签页的媒体状态 |
| S-3 | 活跃标签页自动切换算法 | `sw/hub/store.ts` → `recomputeActiveTab` | 优先焦点标签 → 播放中 → 最近活跃 |
| S-4 | 标签页关闭清理 | `sw/index.ts` / `store.ts` → `removeTab` | `tabs.onRemoved` 事件触发状态清理 |
| S-5 | 标签页焦点追踪 | `sw/index.ts` / `store.ts` → `setFocusedTab` | `tabs.onActivated` 记录焦点标签 |
| S-6 | 命令下发到 Content Script | `sw/hub/router.ts` → `executeCommand` | 自动定位目标 tab，返回 `Promise<boolean>` |
| S-7 | UI 状态同步推送 | `sw/hub/store.ts` → `notifyUI` | 状态变更后主动推送到 Popup UI |
| S-8 | SW 重启状态恢复 | `sw/hub/router.ts` | `getState` 发现无状态时广播 `queryState` 给所有标签 |
| S-9 | 失效标签自动清理 | `sw/hub/router.ts` | 命令发送失败时自动 removeTab |
| S-10 | 标题/Artist/Artwork 回填 | `sw/hub/router.ts` | iframe 缺失的 title 由 tab.title 回填，artwork 由 favIconUrl 回填 |
| S-11 | 关闭标签页 | `sw/hub/router.ts` | `chrome.tabs.remove()` |
| S-12 | 激活标签页（切换焦点） | `sw/hub/router.ts` | `chrome.tabs.update` + windowId 校验后 `chrome.windows.update` |
| S-13 | 桌面命令响应 | `sw/hub/router.ts` → `handleDesktopMessage` | 执行命令后发 `res` 回给桌面端 |
| S-14 | GetMediaList 命令处理 | `sw/hub/router.ts` → `handleDesktopMessage` | 返回完整媒体列表快照给桌面端 |
| S-15 | MediaList 事件推送（节流） | `sw/hub/store.ts` → `notifyDesktop` | 100ms debounce 后发 `evt/MediaList` 给桌面 |

📁 **空目录预留**：`sw/tabs/` — 预计用于独立的标签页管理逻辑
